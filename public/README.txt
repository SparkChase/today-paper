今天这张纸 · 桌面 Chrome 扩展

安装
1. 解压 ZIP，把 today-paper 文件夹放到你打算保留的位置。
2. 在 Chrome 地址栏输入 chrome://extensions，打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 manifest.json 的 today-paper 文件夹。
4. 在 Chrome 工具栏的「扩展程序」菜单点「今天这张纸」，就会打开侧栏。也可以把它固定到工具栏。

用法
· 选一个区域写，点「记下」保存。待办和待看也可以用 Enter 提交，写一段文字时用 ⌘/Ctrl + Enter 提交。
· 「加一个区域」可以新建文字或可勾选区域，第二天继续使用。
· 点日期或左右箭头翻看过去的纸。点「抄到今天」可以把某条记录复制到今天的同一区域。
· 记录保存在当前 Chrome 用户资料里。移除扩展会清除这些记录。
