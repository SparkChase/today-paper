# 《今天这张纸》隐私说明

《今天这张纸》在 Chrome 侧栏记录笔记。文字、链接、图片、日期、分区和勾选状态存放在当前 Chrome 用户资料中。扩展不要求创建账号，不把记录或剪贴板内容发送到开发者服务器，也不使用分析或广告服务。

在输入框主动粘贴时，扩展接收这次粘贴提供的图片，并在本机生成预览。确认保存后，图片写入本地笔记。点击「复制图片」时，扩展将当前预览放入系统剪贴板。

导出备份和下载分享图时，Chrome 会在设备上保存文件。导入仅处理用户主动选择的备份文件。若用户通过聊天或其他服务发送文件，该服务按其自身规则处理文件。

用户可以删除单条记录，或通过移除扩展清除该安装的本地数据。已经下载的备份和图片由用户自行管理。遇到隐私问题可以在 [GitHub 仓库](https://github.com/SparkChase/today-paper/issues) 联系维护者，请勿在公开问题中附上私人笔记。
