# Agent Note: 整本备份与单页分享

Status: implemented

## Problem

早期版本将纸页和贴图放在 Chrome 本地存储。用户换浏览器资料或从开发版迁往商店版时，需要完整携带笔记与附件，并能分享选中的内容。

## Decision

备份以有版本号的 JSON 包含分区、日期、记录和被引用的图片。导入兼容旧版控制台导出的本地存储对象。原记录标识和内容相同则跳过，标识相同但内容不同则保留两个版本。冲突副本标识由内容派生，重复导入不会反复产生同一个版本。图片标识冲突时也为不同内容分配独立标识。

后台的普通写入与侧栏导入使用同一个 Web Lock。确认导入时重新核对修订号，期间有其他写入便显示新预览。记录和附件在同一次本地存储写入中提交。

分享页本地绘制 PNG，预览与复制、下载使用同一份文件。只有用户勾选的分区会进入绘制流程。待办默认选中，其余分区由用户选择。

## Alternatives considered

把整本文件发给 service worker 可复用原有的写队列，但消息体随附件增长。共享锁允许侧栏直接提交，避免通过扩展消息传输图片。整本替换可以精确回退，首版使用合并保护本机新增记录。

## Consequences

更换设备时只需一个文件。导入会在内存中解析备份，处理图片较多的文件时耗时随文件大小增长。分享超长页面时降低输出分辨率，超出可读范围时提示减少选中分区。浏览器测试覆盖下载、重复导入、冲突、预览失效、旧格式恢复以及分享范围。
