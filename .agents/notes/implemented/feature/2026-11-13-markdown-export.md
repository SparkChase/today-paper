# Agent Note: 导出 Markdown 纸页和贴图

Status: implemented

## Problem

分享图保留了纸张样式，文本难以继续编辑。JSON 可以恢复笔记，外部编辑器却无法直接把它当作日期笔记打开。

## Decision

分享入口导出勾选分区，历史入口导出命中筛选的完整纸页，范围包含尚未展开的列表结果。每个日期对应一个 Markdown 文件。无图单页直接下载，其他情况使用 ZIP，图片通过相对路径引用，同一图片只打包一次。待办保留勾选状态，链接沿用纸页的识别规则，笔记内容按普通文字转义。

导出在现有的笔记写锁内读取选中页和附件，取得同一份快照后释放锁，再生成下载文件。图片丢失时提示失败，避免生成引用断开的文件。

## Alternatives considered

把 Base64 图片嵌入单个 Markdown 文件会放大文本，而且编辑器不一定支持 data URL。单独下载多份文件会增加整理成本，也容易移动笔记时漏掉附件。ZIP 保持目录结构，解压后仍可逐页编辑。

## Consequences

原有笔记无需迁移。Markdown 表达日期、分区、文字、待办和链接，纸张样式由分享图提供。ZIP 生成需要在内存中暂存所选文件，数据较多时可以分日期范围导出。
